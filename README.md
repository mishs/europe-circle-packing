# Europe Circle Packing Visualization

A data visualization project using Angular 17+, D3.js, Angular Material, and NgRx.
Visualizes European countries by region, sized by population or land area (toggle).

## Features
- Circle packing D3 viz grouped by region, scalable by population or land area
- Click country for side drawer with full stats, flag, and Wikipedia link
- Angular Material UI, responsive, accessible, minimal NgRx
- Production ready, easy to extend for more regions/data

## Getting Started

```bash
npm install
ng serve
